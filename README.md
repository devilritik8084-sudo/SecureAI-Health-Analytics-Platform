# SecureAI Health Analytics Platform
Educational AI + Big Data + Software Security portfolio project.

## Features
- Synthetic health dataset generation
- Random Forest classification: Low / Moderate / High
- Flask web dashboard
- SQLite prediction history
- Login with PBKDF2 password hashing
- Dataset preview and input validation

## Safety / limitation
This is NOT a medical diagnosis system. It uses artificial data only and must not be used for real healthcare decisions. Never upload real patient data.

## Pydroid 3
1. Install: `pip install Flask scikit-learn`
2. Run `generate_data.py` once.
3. Run `app.py`.
4. Open `http://127.0.0.1:5000`.
5. Demo login: `admin` / `admin123`.

## GKS portfolio description
SecureAI Health Analytics Platform is an educational AI and software-security prototype combining machine learning, data analytics, web development, database storage, authentication, and basic security practices using synthetic health-related data.
